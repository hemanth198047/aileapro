# 03 — Personas and journeys

## Primary personas

### P1 — Absolute beginner (Maya)

- Goal: become employable as an AI engineer in 12–18 months, 8 hours/week.
- Fears: math, “I’m behind,” random YouTube paths.
- Needs: diagnostic honesty, tiny next steps, analogies, lots of practice, encouragement without infantilization.
- Success: finishes foundations + Python + first ML project with demonstrated mastery.

### P2 — Software engineer pivoting (Arjun)

- Goal: LLM / agent engineer role in 4–6 months, 12 hours/week.
- Strengths: Python/JS, systems, git.
- Gaps: ML theory, evals, RAG production patterns.
- Needs: skip known programming, diagnostic that respects existing skill, labs and system design, interview mode.

### P3 — Data scientist deepening (Elena)

- Goal: generative AI + MLOps credibility.
- Needs: map classical ML to modern LLMOps, evaluation lab, research papers tied to practice.

### P4 — Researcher / grad student (Kenji)

- Goal: reproduce papers, stay current, write better experiments.
- Needs: paper explainer with citations, literature maps, research projects, evolution mode.

### P5 — AI product manager (Priya)

- Goal: specify, evaluate, and govern AI products without fake technical fluency.
- Needs: conceptual mastery, system-design literacy, evals, responsible AI, lighter code tracks.

### P6 — Curriculum author / admin (Sam)

- Goal: keep content correct and current.
- Needs: studio, critic, impact simulation, update center, rollback.

### P7 — Platform operator (Ops)

- Goal: cost, reliability, safety, abuse.
- Needs: observability, rate limits, sandbox health, audit logs.

## Secondary personas

- Mentor / reviewer (community later).
- Hiring manager viewing portfolio (read-only artifacts).
- Enterprise admin (later tenant).

## Learning paths (first-class)

AI Beginner, AI Engineer, ML Engineer, Deep Learning Engineer, Generative AI Engineer, LLM Engineer, AI Agent Engineer, Computer Vision Engineer, NLP Engineer, Data Scientist, AI Product Manager, AI Architect, AI Researcher, AI Security Engineer, MLOps/LLMOps Engineer, AI Entrepreneur, Custom.

Each path is a **projection over the knowledge graph**, not a duplicated copy of all content.

## Golden journeys (must work end-to-end)

### J1 — First week

Register → verify email → onboarding goals/hours/style → diagnostic (adaptive, 20–40 items mixed) → roadmap → first knowledge unit (why + prereq check + ELI5 + beginner + exercise) → tutor question → dashboard next action.

### J2 — Concept mastery

Open topic → multi-level explain → visual → code in lab → guided exercise → independent exercise → quiz → spaced cards scheduled → mastery state updates → related concepts + next recommendation.

### J3 — Project to portfolio

Project studio brief → milestones → AI mentor (hints, not dump) → sandboxed runs → automated tests where possible → architecture review → artifact + reflection → portfolio.

### J4 — Field change

Discovery agent finds model/API change → verify sources → impact score → proposed micro-lesson + migration → human/auto gate → learner sees “AI changed since you last learned RAG” → 15-minute update + optional assessment.

### J5 — Author publish

Admin generates quiz draft → critic flags difficulty mismatch → author edits → validation workflow → version bump → changelog visible to learners who completed old version.

## Anti-journeys (must not happen)

- Mark complete on scroll.
- Tutor pastes final exam answers without teaching.
- Code runs on API pod.
- News item silently rewrites linear algebra.
- Fake paper citations.
- Same news feed for PM and researcher.
